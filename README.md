# Java Car Registration

## Technologies
- Java
- Scanner
- Arrays
- Object-Oriented Programming (OOP)

## Features
- Register up to 50 cars.
- Store each car's model and price.
- Display the registered car models.
- Count the registered cars.
- Calculate the total price of all registered cars.

## How to Run
1. Compile `Car.java` and `CarForm.java`.
2. Run the `CarForm` class.
3. Enter the number of cars you want to register.
4. Enter each car's model and price.
5. View the registration summary.
